# Haunted Basement

A WebXR page for the Meta Quest 3 browser that turns a room into a haunted one in color passthrough:
candles on tables and desks, cobwebs in the wall corners, and a ghost that drifts toward you.

Open the GitHub Pages link in the Quest browser, press **Enter AR**, and allow it to use your room setup
(run Space Setup on the headset first so it knows your walls and furniture).

- **Trigger**: place a candle where you point
- **Grip**: summon the ghost
- **A**: clear all candles
- **B**: show the room scan as a wireframe

`lib/` holds a copy of three.js (0.170) so the page has no outside dependencies.
