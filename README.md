# Haunted Basement

A WebXR page for the Meta Quest 3 browser that turns a room into a haunted castle tower in color passthrough:
stone walls over your real walls, one arched window with a full moon outside, candles on tables and desks,
cobwebs in the wall corners, bats circling the ceiling, and a Boo that sneaks up on you only while you are not looking.

Open the GitHub Pages link in the Quest browser, press **Enter AR**, and allow it to use your room setup
(run Space Setup on the headset first so it knows your walls and furniture).

- **Trigger**: place a candle where you point
- **Grip**: summon the ghost
- **A**: clear all candles
- **B**: show the room scan as a wireframe
- **X**: castle walls on/off
- **Y**: move the window to the next wall

`lib/` holds a copy of three.js (0.170) so the page has no outside dependencies.
